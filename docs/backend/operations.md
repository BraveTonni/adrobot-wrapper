# Эксплуатация

## Запуск

Локальный запуск через `make run` использует Docker Compose. Создайте
API-key secret по инструкции в [общем руководстве по контейнерам](../containers.md).
Для прямого запуска процесса используйте переменные окружения или
`backend/.env`. В рабочей среде получайте ключ через менеджер секретов и не
храните его в репозитории.

При запуске через Compose миграции выполняет сервис `migrate`. При прямом
запуске процесса или в production примените миграции отдельно:

```bash
cd backend
uv run alembic upgrade head
```

Затем запустите ASGI-приложение согласно окружению. Для локального запуска
используйте `make run`; в production следует запускать Uvicorn без `--reload`
и настроить количество workers согласно инфраструктуре.

## Проверка состояния

`GET /api/v1/health` выполняет `SELECT 1` в базе данных. Этот маршрут проверяет
доступность БД, но не проверяет соединение с Keitaro. Ошибки интеграции видны
по ответам API и структурированным JSON-логам.

`GET /api/v1/operations` возвращает последние 50 операций: успешные изменения,
откаты и неудачные откаты кампаний.

## Миграции и данные

SQLite по умолчанию создаёт файл `backend/adrobot.db`, если команды выполняются
из `backend/`. Для другой базы задайте `DATABASE_URL`. Миграции запускаются
отдельно и автоматически при старте приложения не применяются.

Журнал операций не заменяет резервное копирование базы. План резервного
копирования выбирается для конкретной базы и среды развертывания.

Backend поддерживает SQLite по умолчанию и PostgreSQL через `asyncpg`; для
Compose задайте соответствующий URL в secret-файле `database_url`. Для
PostgreSQL используйте TLS на соединении и резервное копирование средствами
провайдера базы. SQLite остаётся удобным вариантом для локального однопроцессного
запуска.

## Ограничения

- Справочники кэшируются в памяти каждого процесса отдельно.
- Keitaro и локальная база не участвуют в общей транзакции. Перед удалённой
  мутацией создаётся запись `pending`; если её создать нельзя, операция не
  начинается. Ошибка финализации оставляет эту запись для ручной сверки.
- Изменение offers отправляет весь список. Параллельная правка того же потока
  может быть перезаписана, так как условная запись не реализована.
