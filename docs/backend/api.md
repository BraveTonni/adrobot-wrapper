# HTTP API

Все маршруты имеют префикс `/api/v1`. Входные и выходные данные передаются
в JSON. Значения ограничений ниже соответствуют текущим HTTP-схемам.

Все маршруты `/campaigns`, `/offers`, `/references` и `/operations` требуют заголовок
`Authorization: Bearer <API_ACCESS_TOKEN>`. Для `POST /campaigns` также нужен
уникальный `Idempotency-Key` длиной от 16 до 128 символов. Повтор с тем же
ключом и телом возвращает сохранённый ответ; повтор с другим телом или пока
первый запрос ещё выполняется получает `409`. См. [доступ к API](security.md).

## Состояние и справочники

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/v1/health` | Проверить подключение к базе данных |
| `GET /api/v1/references` | Получить домены, группы кампаний и источники трафика |
| `GET /api/v1/offers?search=&limit=20` | Найти офферы; `limit`: от 1 до 100 |
| `GET /api/v1/operations` | Последние 50 записей аудита |

Поиск офферов выполняется без учёта регистра по имени и ID.

## Кампании

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/v1/campaigns?search=` | Найти кампании по имени с постраничной загрузкой из Keitaro; поиск возвращает до 500 совпадений |
| `POST /api/v1/campaigns` | Создать кампанию и два потока; ответ `201` |
| `GET /api/v1/campaigns/{campaign_id}` | Получить кампанию и её потоки |

Тело `POST /api/v1/campaigns`:

```json
{
  "name": "Spring campaign",
  "geo": "US",
  "offer_id": 42,
  "domain_id": 1813,
  "group_id": 10332,
  "source_id": 836
}
```

Обязательны `name`, `geo` и положительный `offer_id`. `geo` — код страны
ISO 3166-1 alpha-2; пробелы удаляются, код приводится к верхнему регистру.
`domain_id`, `group_id` и `source_id` можно не указывать: тогда применяются
значения по умолчанию из конфигурации.

## Офферы потока

| Метод и путь | Назначение |
| --- | --- |
| `POST /api/v1/campaigns/{campaign_id}/streams/{stream_id}/offers` | Добавить оффер; ответ `201` |
| `DELETE /api/v1/campaigns/{campaign_id}/streams/{stream_id}/offers/{offer_id}` | Удалить оффер |

Тело добавления:

```json
{
  "offer_id": 42
}
```

Операции доступны только для потока, который использует офферы. Нельзя добавить
дубликат, удалить отсутствующий оффер или удалить последний оффер потока.

## Ошибки

| HTTP | Смысл |
| --- | --- |
| `404` | Кампания, поток или оффер не найден |
| `409` | Операция конфликтует с текущим состоянием |
| `422` | Ошибка валидации входных данных FastAPI/Pydantic |
| `502` | Ошибка или некорректный ответ Keitaro |
| `429` | Слишком много неудачных попыток авторизации; см. `Retry-After` |

Ошибки имеют форму `{"detail": "..."}`.
