# adrobot-wrapper

Веб-сервис для управления кампаниями и офферами через Keitaro Admin API.
Документация хранится рядом с исходным кодом и проходит проверку вместе с ним.

## Возможности

- Создание кампании с гео-потоком и потоком оффера, с откатом при сбое и защитой
  от повторного создания.
- Просмотр кампаний, офферов и справочников Keitaro.
- Редактор офферов: изменения сразу публикуются в Keitaro, доли всегда дают в
  сумме 100%, последний оффер потока защищён.
- Журнал операций в PostgreSQL или SQLite.
